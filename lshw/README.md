# lshw

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита комплексной инвентаризации аппаратного обеспечения компьютера (Hardware Lister).

### Использование
```bash
lshw [ОПЦИИ]...
```

### Поддерживаемые опции
- `-short` — краткий сводный вывод оборудования в виде таблицы системных путей и классов устройств.
- `-class <класс>` — фильтрация устройств по указанному классу (`cpu`, `memory`, `bus`, `storage`, `network`, `display`).
- `-json` — экспорт информации об оборудовании в машиночитаемом формате JSON.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Сканируемые компоненты
- Центральный процессор (CPUID, частота, поддерживаемые наборы инструкций).
- Оперативная память (общий объем, свободная память).
- Шина PCI и подключенные контроллеры.
- Сетевые адаптеры (Ethernet, MAC-адреса).
- Блочные накопители и видеоадаптеры.

## Статус реализации

- **Реализовано**: сканирование CPUID, шины PCI, сетевых интерфейсов, дисков, вывод в форматах текста, краткой таблицы (`-short`) и JSON (`-json`).
- **Не реализовано**: опрос таблиц DMI/SMBIOS материнских плат (серийные номера шасси, слоты памяти DIMM) и датчиков температур/вентиляторов (hwmon).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/lshw`
