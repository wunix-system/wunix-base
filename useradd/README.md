# useradd

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита создания новой учетной записи пользователя в операционной системе Wunix.

### Использование
```bash
useradd [ОПЦИЯ]... ИМЯ_ПОЛЬЗОВАТЕЛЯ
```

### Поддерживаемые опции
- `-m, --create-home` — создать домашний каталог пользователя (по умолчанию `/home/<имя>`) и скопировать базовые профили.
- `-d, --home <каталог>` — явно указать путь к домашнему каталогу.
- `-s, --shell <оболочка>` — командная оболочка пользователя (по умолчанию `/bin/wsh`).
- `-u, --uid <UID>` — числовой идентификатор пользователя (если не указан, выделяется следующий свободный UID >= 1000).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Модифицируемые файлы
- `/etc/passwd` — добавление учетной записи пользователя.
- `/etc/shadow` — создание заблокированной начальной записи (требуется задание пароля через `passwd`).
- `/etc/group` — создание персональной группы пользователя с соответствующим GID.

## Статус реализации

- **Реализовано**: выделение свободных UID/GID, создание домашнего каталога (`-m`), корректное форматирование записей в `/etc/passwd`, `/etc/shadow`, `/etc/group`.
- **Не реализовано**: копирование шаблонных файлов из скелетного каталога `/etc/skel` (создается чистый домашний каталог с правами `0700`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/useradd`
