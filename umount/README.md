# umount

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита размонтирования файловых систем из общего дерева виртуальной файловой системы (VFS) Wunix.

### Использование
```bash
umount [ОПЦИИ] <каталог | устройство>
```

### Поддерживаемые опции
- `-f, --force` — принудительное размонтирование файловой системы даже при наличии занятых ресурсов.
- `-v, --verbose` — подробный вывод сообщений о процессе размонтирования.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Принцип работы
Сбрасывает буферы записи файловой системы на диск (`sync`) и отсоединяет указанную точку монтирования с помощью системного вызова `umount2`.

## Статус реализации

- **Реализовано**: размонтирование по пути точки монтирования или имени блочного устройства, сброс кэшей данных, флаги `-f` и `-v`.
- **Не реализовано**: ленивое размонтирование (`-l, --lazy`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/umount`
