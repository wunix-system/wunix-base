# fbset

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита инспекции и настройки параметров графического кадрового буфера дисплея (Framebuffer / Limine FB / VirtIO GPU).

### Использование
```bash
fbset [ОПЦИИ]...
```

### Поддерживаемые опции
- `-i, --info` — подробный вывод характеристик кадрового буфера: разрешение, битовая глубина (bpp), шаг строки (pitch), физический адрес в памяти (MMIO), цветовой формат.
- `-x <ширина>` — установка горизонтального разрешения экрана в пикселях.
- `-y <высота>` — установка вертикального разрешения экрана в пикселях.
- `-depth <bpp>` — установка битовой глубины цвета (16, 24, 32 bpp).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: чтение текущей геометрии и характеристик кадрового буфера через интерфейсы `/dev/fb0` и псевдофайлы ядра `/proc/fb`, форматированный отчет о видеорежиме.
- **Не реализовано**: динамическое переключение видеорежимов «на лету» без перезапуска графического драйвера ядра (зависит от возможностей виртуального видеоадаптера гипервизора).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/fbset`
