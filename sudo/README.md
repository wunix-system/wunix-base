# sudo

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита выполнения команд с привилегиями суперпользователя (root) авторизованными пользователями.

### Использование
```bash
sudo [ОПЦИЯ] КОМАНДА [АРГУМЕНТЫ...]
```

### Поддерживаемые опции
- `-u <пользователь>` — запуск команды от имени указанного пользователя вместо root.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Политика доступа
Пользователь должен состоять в административной группе `wheel` (или `sudo`) в файле `/etc/group`. Для подтверждения полномочий запрашивается текущий пароль вызывающего пользователя.

## Статус реализации

- **Реализовано**: проверка принадлежности к группе администраторов `wheel`, запрос и верификация пароля через `/etc/shadow`, повышение привилегий до UID=0 и запуск целевой команды с аргументами.
- **Не реализовано**: детальная конфигурация правил в файле `/etc/sudoers` (NOPASSWD, раздельные списки разрешенных бинарников для каждого пользователя) — используется базовая модель доступа через группу `wheel`.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/sudo`
