# lspci

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита сканирования системной шины PCI и вывода сведений о подключенных контроллерах и устройствах.

### Использование
```bash
lspci [ОПЦИИ]...
```

### Поддерживаемые опции
- `-v` — подробный вывод информации об устройствах (линии IRQ, базовые регистры BAR, размеры адресов MMIO).
- `-vv` — максимально подробный вывод (дополнительные параметры и флаги шины).
- `-n` — вывод числовых идентификаторов Vendor ID и Device ID вместо текстовых названий.
- `-s [[[[<домен>]:]<шина>]:][<устройство>][.[<функция>]]` — показ информации только об устройстве с указанным слотом PCI.
- `-t` — отображение топологии PCI в виде дерева шин.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Встроенная база устройств
Содержит встроенный справочник известных вендоров и устройств (Red Hat VirtIO, Intel, Realtek, AMD, VMware).

## Статус реализации

- **Реализовано**: сканирование шины PCI через порты конфигурации `0xCF8`/`0xCFA` и sysfs, декодирование Vendor/Device ID, подробные уровни вывода (`-v`, `-vv`), числовой режим (`-n`), фильтрация по слотам (`-s`).
- **Не реализовано**: декодирование расширенных возможностей PCI Express (PCIe Capabilities, MSI-X расширенные таблицы).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/lspci`
