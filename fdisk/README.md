# fdisk

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита просмотра и инспекции таблиц разделов дисковых накопителей (MBR и GPT).

### Использование
```bash
fdisk [ОПЦИИ] <устройство>
```

### Поддерживаемые опции
- `-l, --list` — вывод списка и подробной информации о разделах указанного блочного устройства (или `/dev/vda` по умолчанию).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Отображаемая информация
- Тип разметки диска (MBR, GPT).
- Список разделов, флаг загрузочного раздела (Bootable), начальный сектор LBA, размер раздела в секторах и мегабайтах.
- Идентификаторы типов файловых систем (FAT12, FAT16, FAT32, NTFS, Linux, Linux Swap, GPT Protective).

## Статус реализации

- **Реализовано**: сканирование диска, чтение нулевого сектора (MBR), разбор 4 основных записей таблицы разделов, определение GPT Protective MBR, вывод геометрии разделов и типов ФС.
- **Не реализовано**: интерактивное меню редактирования/создания разделов (fdisk interactive shell), создание новых разделов GPT и запись измененной таблицы на диск (для начальной установки используется `winstall`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/fdisk`
