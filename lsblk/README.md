# lsblk

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита вывода списка и структуры доступных блочных устройств хранения данных в Wunix.

### Использование
```bash
lsblk [ОПЦИИ]
```

### Поддерживаемые опции
- `-a, --all` — отображение всех устройств, включая пустые накопители.
- `-l, --list` — вывод списка в линейном строковом формате.
- `-b, --bytes` — отображение точного размера накопителя в байтах вместо форматированных единиц.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Отображаемые параметры
Опрашивает `/sys/block` и ядро Wunix:
- `NAME` — имя блочного устройства или раздела (например, `vda`, `vda1`).
- `MAJ:MIN` — старший и младший номера устройства.
- `RM` — флаг съемного носителя (removable).
- `SIZE` — емкость накопителя.
- `RO` — признак устройства, доступного только для чтения.
- `TYPE` — тип (диск, раздел, RAM-диск).
- `MOUNTPOINT` — точка монтирования в дереве VFS.

## Статус реализации

- **Реализовано**: сканирование виртуальных блочных устройств VirtIO Block и RAM-дисков, разбор MBR-разделов, сопоставление с точками монтирования VFS.
- **Не реализовано**: топологические параметры дисков (размеры физических секторов, очереди дискового ввода-вывода I/O scheduler).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/lsblk`
