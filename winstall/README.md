# winstall

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Мастер установки операционной системы Wunix на постоянный дисковый накопитель (Wunix OS Installer).

### Использование
```bash
winstall
```

### Архитектура и этапы установки
Предоставляет интерактивный псевдографический интерфейс (TUI) с навигацией и поддержкой цветов:
1. **Экран приветствия** — выбор режима установки или тестирования системы.
2. **Выбор диска** — сканирование блочных накопителей (`/dev/vda`, `/dev/sda` и др.) с отображением их емкости.
3. **Разметка накопителя** — запись главной загрузочной записи (MBR) и создание основного раздела.
4. **Форматирование** — форматирование раздела в файловую систему FAT32.
5. **Копирование файлов** — перенос ядра Wunix, базового набора системных утилит и конфигурационных файлов из Live-образа на целевой диск.
6. **Настройка системы** — задание сетевого имени хоста (hostname), пароля суперпользователя `root` и создание учетной записи обычного пользователя.
7. **Конфигурация сети** — настройка сетевого интерфейса и DNS.
8. **Установка загрузчика** — развертывание и конфигурация загрузчика Limine (`limine.conf`).

## Статус реализации

- **Реализовано**: TUI-интерфейс, сканирование накопителей, разметка MBR, форматирование FAT32, копирование системных файлов, создание пользователей и установка загрузчика Limine.
- **Не реализовано**: разметка дисков по стандарту GPT с загрузкой через UEFI (поддерживается режим BIOS/MBR), расширенная ручная схема разбиения на несколько разделов (`/home`, `/var`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/winstall`
