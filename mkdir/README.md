# mkdir

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита создания новых каталогов в файловой системе Wunix (POSIX mkdir).

### Использование
```bash
mkdir [КЛЮЧИ]... КАТАЛОГ...
```

### Поддерживаемые опции
- `-p, --parents` — создание всей цепочки промежуточных родительских каталогов, если они отсутствуют; не выдает ошибку, если каталог уже существует.
- `-m, --mode=РЕЖИМ` — задание прав доступа создаваемого каталога в восьмеричном формате (например, `0755`).
- `-v, --verbose` — подробный вывод сообщений о каждом созданном каталоге.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: вызов системного вызова `mkdir`, создание родительских каталогов `-p`, явная установка прав доступа `-m`, подробный режим `-v`, локализация сообщений об ошибках.
- **Не реализовано**: на текущий момент все функции утилиты полностью реализованы.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/mkdir`
