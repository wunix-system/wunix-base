# rmdir

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита удаления пустых каталогов из файловой системы Wunix (POSIX rmdir).

### Использование
```bash
rmdir [КЛЮЧИ]... КАТАЛОГ...
```

### Поддерживаемые опции
- `-v, --verbose` — подробный вывод сообщений о каждом удаленном каталоге.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Принцип работы
Выполняет системный вызов ядра `rmdir`. Каталог успешно удаляется только в том случае, если он не содержит файлов или поддиректорий.

## Статус реализации

- **Реализовано**: проверка и удаление пустых каталогов, подробный вывод `-v`, локализованные сообщения об ошибках (каталог не пуст, каталог не найден).
- **Не реализовано**: флаг рекурсивного удаления пустых каталогов вверх по пути (`-p, --parents`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/rmdir`
