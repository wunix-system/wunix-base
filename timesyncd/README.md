# timesyncd

> Служба входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Системный демон автоматической фоновой синхронизации системных часов по протоколу NTP/SNTP (RFC 5905, RFC 4330).
Служба считывает конфигурацию из `/etc/timesyncd.conf`, выполняет периодический опрос пула NTP-серверов, корректирует системные часы ядра и записывает состояние в `/run/timesync/status`.

### Использование
```bash
timesyncd [ОПЦИИ]...
```

### Поддерживаемые опции
- `-1, --once` — однократная синхронизация с выходом по завершении.
- `-d, --daemon` — непрерывная фоновая работа с адаптивным интервалом опроса.
- `-v, --verbose` — подробный вывод процесса синхронизации.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии службы.
