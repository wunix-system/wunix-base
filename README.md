# wunix-base

> Базовый набор системных и административных утилит операционной системы Wunix.

## Описание

`wunix-base` — официальная коллекция стандартных консольных программ пространства пользователя (Ring 3), обеспечивающих базовое функционирование операционной системы Wunix.

Все утилиты разработаны на языке Rust для bare-metal архитектуры `x86_64-unknown-none` с минимальным оверхедом и опираются на системную библиотеку [`libwunix`](../wunix/libs/libwunix). Каждая программа строго следует принципам надежности, чистоты типов, валидации входных данных и мультиязычности (RU/EN).

## Каталог утилит

Базовый набор включает 53 полнофункциональные утилиты, разделенные по функциональным подсистемам:

### 1. Процессы, супервизия и системный статус
| Программа | Назначение |
| :--- | :--- |
| **`init`** | Корневой супервизор и первый процесс пространства пользователя (PID 1). Монтирует VFS и разбирает cmdline ядра. |
| **`system`** | Менеджер и супервизор системных служб: управление жизненным циклом демонов (start, stop, restart, status, list, logs, edit, create, enable, disable). |
| **`login`** | Менеджер аутентификации пользователей и запуска пользовательской сессии. |
| **`top`** | Интерактивный динамический мониторинг потоков, аптайма и использования памяти ядра. |
| **`free`** | Отображение объема свободной и занятой физической оперативной памяти. |
| **`uname`** | Вывод версии ядра, архитектуры и системных характеристик ОС. |
| **`time`** | Точный замер времени выполнения переданной команды. |
| **`date`** | Отображение и установка системного времени и даты (ISO 8601, RFC 5322). |
| **`hwclock`** | Прямое чтение и синхронизация аппаратных часов CMOS (RTC MC146818). |
| **`timedatectl`** | Управление часовыми поясами, системным временем и статусом синхронизации. |
| **`ntpdate`** | Разовая синхронизация системного времени по протоколу NTP через сокеты UDP. |
| **`timesyncd`** | Фоновый демон периодической синхронизации времени с NTP-серверами. |
| **`shutdown`** | Корректный останов процессов и завершение работы компьютера (ACPI / QEMU poweroff). |
| **`reboot`** | Перезагрузка компьютера через контроллер 8042 клавиатуры и системный вызов ядра. |

### 2. Файловые операции и навигация по VFS
| Программа | Назначение |
| :--- | :--- |
| **`cat`** | Последовательное чтение и вывод содержимого файлов в терминал. |
| **`ls`** | Отображение содержимого директорий с подсветкой типов файлов и подробным форматом (`-l`, `-a`, `-h`). |
| **`touch`** | Создание пустых файлов или обновление времени модификации. |
| **`mkdir`** | Создание новых директорий (включая создание родительских каталогов `-p`). |
| **`rm`** | Удаление файлов из файловой системы. |
| **`rmdir`** | Безопасное удаление пустых каталогов. |
| **`chmod`** | Изменение битов прав доступа файлов и директорий (rwxrwxrwx). |
| **`chown`** | Смена владельца (UID) и группы (GID) файла. |
| **`ln`** | Создание символических (symlink) и жестких ссылок. |
| **`readlink`** | Чтение и вывод целевого пути символической ссылки. |
| **`pwd`** | Вывод канонического пути текущей рабочей директории. |
| **`clear`** | Очистка экрана терминала через ANSI-последовательность VT100. |
| **`echo`** | Печать аргументов в терминал с поддержкой флагов `-n` и `-e`. |

| Программа | Назначение |
| :--- | :--- |
| **`whoami`** | Вывод имени учетной записи текущего пользователя. |
| **`id`** | Детальный вывод реального и эффективного UID, GID и дополнительных групп. |

| **`useradd`** | Создание новых учетных записей пользователей и генерация домашних директорий. |
| **`userdel`** | Удаление учетных записей из баз данных системы. |
| **`su`** | Запуск оболочки с подменой идентификатора пользователя (root по умолчанию). |
| **`sudo`** | Привилегированное выполнение команд доверенными пользователями. |

| Программа | Назначение |
| :--- | :--- |

### 5. Дисковая подсистема и накопители
| Программа | Назначение |

## Архитектурные стандарты реализации

Все утилиты `wunix-base` спроектированы в соответствии со строгими правилами системной инженерии:
1. **Принцип единой ответственности (SRP)**:
   - Файл `main.rs` содержит только точку входа `_start`, парсинг CLI аргументов и диспетчеризацию.
   - Сбор данных, математика и сетевые протоколы вынесены в доменные модули (`collect.rs`, `client.rs`).
   - Форматирование таблиц и цвета вынесены в модули представления (`format.rs`).
2. **Нулевой runtime-оверхед**:
   - Отсутствие тяжелых стандартных библиотек (`#![no_std]`).
   - Использование vDSO и прямых системных вызовов через `libwunix`.
3. **Локализация (i18n)**:
   - Полная поддержка двуязычного вывода сообщений (русский и английский языки) через функцию `t()`.

## Сборка

Благодаря конфигурации Cargo Workspace репозиторий поддерживает как массовую компиляцию всех утилит, так и сборку отдельных пакетов:

### Сборка всего набора утилит сразу
```bash
# Сборка всех 53 утилит одной командой из корня репозитория
cargo build --release
```

### Сборка конкретной утилиты
```bash
# Через ключ пакета:
cargo build -p <имя_утилиты> --release

# Либо переходом в директорию программы:
cd <имя_утилиты>
cargo build --release
```

Скомпилированные бинарники располагаются в общем каталоге `target/x86_64-unknown-none/release/` либо локальном `target/` соответствующей программы.
