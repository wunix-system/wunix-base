# host

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита разрешения доменных имен (DNS-клиент) и выполнения сетевых DNS-запросов (также может вызываться как `nslookup`).

### Использование
```bash
host <доменное_имя | IP-адрес> [DNS-сервер]
nslookup <доменное_имя | IP-адрес> [DNS-сервер]
```

### Возможности
- Прямое разрешение доменных имен в IPv4-адреса (A-записи).
- Обратное разрешение IPv4-адресов в доменные имена (PTR-записи через домен `in-addr.arpa`).
- Возможность указания пользовательского DNS-сервера в качестве второго аргумента.
- При отсутствии пользовательского DNS-сервера используется системный адрес из конфигурации `/etc/resolv.conf` (или DNS по умолчанию).

## Статус реализации

- **Реализовано**: отправка UDP DNS-запросов на порт 53, парсинг ответов A (IPv4) и PTR (обратная зона), поддержка вызова под именами `host` и `nslookup`.
- **Не реализовано**: поддержка IPv6-записей (AAAA), почтовых MX-записей, TXT, SRV, CNAME-цепочек, валидация подписей DNSSEC, работа по протоколу TCP.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/host`
