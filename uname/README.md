# uname

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита вывода системной информации об операционной системе Wunix, версии ядра и архитектуре процессора.

### Использование
```bash
uname [ОПЦИИ]...
```

### Поддерживаемые опции
- `-s, --kernel-name` — имя ядра операционной системы (`Wunix`).
- `-n, --nodename` — сетевое имя узла (hostname).
- `-r, --kernel-release` — номер релиза ядра.
- `-v, --kernel-version` — версия сборки и дата компиляции ядра.
- `-m, --machine` — аппаратная архитектура процессора (`x86_64`).
- `-o, --operating-system` — наименование операционной системы (`Wunix`).
- `-a, --all` — вывод всей системной информации одной строкой в стандартном порядке.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

При вызове без параметров поведение эквивалентно флагу `-s`.

## Статус реализации

- **Реализовано**: системный вызов `uname` (структура `utsname`), полная поддержка всех стандартных флагов POSIX и GNU coreutils.
- **Не реализовано**: на текущий момент все функции утилиты полностью реализованы.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/uname`
