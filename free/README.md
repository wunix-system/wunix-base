# free

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита отображения информации об объеме и использовании оперативной памяти (RAM) и файла подкачки (Swap).

### Использование
```bash
free
```

### Отображаемые параметры
Считывает данные системного вызова `sysinfo` ядра Wunix и выводит значения в байтах:
- `Total` — общий объем физической оперативной памяти.
- `Free` — объем незанятой (свободной) памяти.
- `Used` — объем памяти, используемой ядром и процессами.
- `Buffers` — память, выделенная под системные буферы ядра.
- `Swap` — общий объем и использование пространства подкачки.

## Статус реализации

- **Реализовано**: опрос системного вызова `sysinfo`, расчет показателей используемой памяти, вывод базовой таблицы метрик памяти.
- **Не реализовано**: флаги переключения единиц измерения (`-h, --human` удобочитаемый вывод, `-m` мегабайты, `-g` гигабайты, `-k` килобайты), режим циклического обновления (`-s <интервал>`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/free`
