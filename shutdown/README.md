# shutdown

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита планового и немедленного завершения работы, выключения питания или перезагрузки Wunix.

### Использование
```bash
shutdown [ОПЦИИ]... [ВРЕМЯ] [СООБЩЕНИЕ...]
```

### Поддерживаемые опции
- `-P, -h, --poweroff` — выключить питание компьютера (действие по умолчанию).
- `-r, --reboot` — перезагрузить операционную систему.
- `-H, --halt` — остановить ядро (halt) без отключения питания.
- `-c, --cancel` — отменить ранее запланированное отложенное выключение.
- `-k` — отправить предупредительное сообщение пользователям без реального выключения.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Форматы времени
- `now` — немедленное завершение работы.
- `+m` — выключение через указанное число минут `m`.

## Статус реализации

- **Реализовано**: немедленное выключение питания (`now`), перезагрузка (`-r`), выключение с задержкой по таймеру, рассылка предупреждающего сообщения в терминалы пользователей.
- **Не реализовано**: отмена запланированного выключения (`-c, --cancel`) — на данный момент не поддержана подсистемой отложенных событий ядра.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/shutdown`
