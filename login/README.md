# login

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Программа аутентификации пользователей и инициализации пользовательской сессии в Wunix.

### Использование
```bash
login [-p] [-f пользователь] [пользователь]
```

### Принцип работы
1. Запрашивает имя учетной записи (если не передано в аргументах) и пароль (с отключенным эхо-выводом в терминале).
2. Вычисляет криптографический хэш SHA-512 с солью и сверяет его с эталоном в защищенном файле `/etc/shadow`.
3. При успешной проверке переключает реальный и эффективный UID/GID процесса (`setuid`, `setgid`) на идентификаторы пользователя.
4. Инициализирует системные переменные окружения (`USER`, `LOGNAME`, `HOME`, `SHELL`, `PATH`).
5. Переходит в домашний каталог пользователя и запускает командную оболочку, указанную в `/etc/passwd` (по умолчанию `/bin/wsh`).

## Статус реализации

- **Реализовано**: верификация паролей по SHA-512, интеграция с `/etc/passwd` и `/etc/shadow`, безопасный терминальный ввод, понижение привилегий root, инициализация среды окружения и запуск командного интерпретатора.
- **Не реализовано**: модульная архитектура подключаемой аутентификации PAM (Pluggable Authentication Modules), лимиты ресурсов `/etc/security/limits.conf`.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/login`
