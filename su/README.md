# su

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита переключения текущего идентификатора пользователя на указанную учетную запись.

### Использование
```bash
su [ОПЦИЯ]... [ПОЛЬЗОВАТЕЛЬ]
```

### Поддерживаемые опции
- `-l, --login` — запуск оболочки в режиме входа (login shell): очистка переменных окружения и загрузка профиля целевого пользователя.
- `-s, --shell <оболочка>` — запуск указанной командной оболочки вместо заданной в `/etc/passwd`.
- `-c, --command <команда>` — выполнение указанной команды от имени целевого пользователя с последующим выходом.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

При вызове без имени пользователя выполняется переключение на учетную запись `root`.

## Статус реализации

- **Реализовано**: аутентификация по хэшу SHA-512 в `/etc/shadow`, переключение реального и эффективного UID/GID, запуск командной оболочки, поддержка режима login shell (`-l`).
- **Не реализовано**: сохранение журнала неудачных попыток входа в `syslog`.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/su`
