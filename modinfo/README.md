# modinfo

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита просмотра подробных метаданных и информации о драйверах и модулях ядра Wunix.

### Использование
```bash
modinfo [ОПЦИИ]... <имя_драйвера>
```

### Поддерживаемые опции
- `-F, --field <поле>` — вывод только значения конкретного поля (например, `description`, `author`, `license`, `version`).
- `-a, --author` — эквивалентно `-F author` (вывод автора).
- `-d, --description` — эквивалентно `-F description` (вывод описания).
- `-l, --license` — эквивалентно `-F license` (вывод лицензии).
- `-n, --filename` — вывод пути к модулю или псевдониму драйвера.
- `-p, --parameters` — вывод списка поддерживаемых параметров настройки.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: извлечение метаданных модулей из `/sys/module` и ядра, поддержка фильтрации по полям, вывод поддерживаемых PCI алиасов устройств.
- **Не реализовано**: на текущий момент все функции утилиты полностью реализованы.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/modinfo`
