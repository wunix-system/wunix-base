# echo

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Стандартная утилита вывода текстовых строк и переданных аргументов в стандартный поток вывода (POSIX echo).

### Использование
```bash
echo [АРГУМЕНТЫ...]
```

### Принцип работы
Выводит все переданные аргументы командной строки, разделяя их одиночными пробелами, и завершает вывод символом перевода строки (`
`).

## Статус реализации

- **Реализовано**: базовый вывод строковых аргументов с разделением пробелами и завершающим переводом строки.
- **Не реализовано**: расширенные флаги интерпретации escape-последовательностей (`-e`, `-E`) и подавления перевода строки (`-n`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/echo`
