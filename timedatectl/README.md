# timedatectl

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита управления системным временем, датой, аппаратными часами RTC и часовыми поясами Wunix.

### Использование
```bash
timedatectl [ОПЦИИ]... [КОМАНДА]
```

### Поддерживаемые команды
- `status` — отображение подробного статуса: местное время, время по шкале UTC, время аппаратных часов RTC, текущий часовой пояс, смещение.
- `set-time <YYYY-MM-DD HH:MM:SS>` — установка системного времени и даты.
- `set-timezone <ЗОНА>` — выбор системного часового пояса (обновление `/etc/localtime`).
- `list-timezones` — вывод списка всех поддерживаемых часовых поясов.
- `set-local-rtc <0|1>` — настройка хранения времени в аппаратных часах RTC (0 — UTC, 1 — местное время).

### Поддерживаемые опции
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: вывод статуса времени, синхронизация с RTC, установка времени и часового пояса через конфигурационные файлы Wunix, управление сетевой синхронизацией по протоколу NTP (`set-ntp 0|1`), отображение детального сетевого статуса `timesync-status` (сервер, задержка, дрейф, смещение).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/timedatectl`
