# ss

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита исследования и вывода статистики активных сетевых сокетов (Socket Statistics, iproute2 ss).

### Использование
```bash
ss [ОПЦИИ]
```

### Поддерживаемые опции
- `-t, --tcp` — отображать TCP-сокеты.
- `-u, --udp` — отображать UDP-сокеты.
- `-l, --listening` — показывать только слушающие сокеты (серверы).
- `-a, --all` — показывать как слушающие, так и установленные сокеты.
- `-n, --numeric` — отображать числовые номера портов вместо символических названий служб.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: опрос псевдофайлов `/proc/net/tcp` и `/proc/net/udp`, разбор состояний сокетов (LISTEN, ESTABLISHED, CLOSE_WAIT и др.), фильтрация протоколов и флагов.
- **Не реализовано**: сокеты локального межпроцессного взаимодействия UNIX domain (`-x`), сокеты протокола IPv6, отображение очередей приема и отправки пакетов (Recv-Q / Send-Q).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/ss`
