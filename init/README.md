# init

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Системный супервизор, первый процесс пространства пользователя Wunix (PID 1) и диспетчер системных служб.

### Назначение
Является корневым процессом, запускаемым ядром Wunix после завершения инициализации оборудования и монтирования начального образа `initramfs`.

### Выполняемые задачи
1. Монтирование обязательных псевдофайловых систем:
   - `/proc` (procfs) — псевдофайловая система процессов и ядра.
   - `/sys` (sysfs) — псевдофайловая система устройств и драйверов.
   - `/dev` (devfs) — файловая система аппаратных узлов и терминалов.
   - `/tmp` (ramfs) — временная файловая система в оперативной памяти.
   - `/run` (ramfs) — каталог состояний служб и PID-файлов (`/run/services/`).
   - `/var/log` — каталог журналов (`/var/log/services/`).
2. Инициализация и автозапуск системных служб:
   - Автоматическое создание каталогов `/etc/services/` и `/etc/services/enabled/`.
   - Запуск всех служб из `/etc/services/enabled/` через утилиту `system start`.
3. Анализ параметров загрузки из `/proc/cmdline`:
   - `mode=install` — автоматический запуск мастера установки `winstall`.
   - `mode=live` — запуск интерактивной сессии командной оболочки `wsh` без авторизации.
   - `root=/dev/vda1` или `mode=disk` — монтирование корневого раздела диска и запуск сервиса авторизации `login`.
   - При отсутствии специальных параметров отображает загрузочное меню с выбором режима работы.
4. Очистка и перехват процессов-сирот (orphan processes) и супервизия консоли пользователя.

## Статус реализации

- **Реализовано**: первичное монтирование VFS, диспетчер автозапуска системных служб (`/etc/services/enabled/`), разбор командной строки ядра, маршрутизация режимов запуска (Live, Installer, Disk), запуск интерактивной консоли и супервизия дочерних процессов.

## Сборка

```bash
cargo build --release --target x86_64-unknown-none
```
