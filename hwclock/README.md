# hwclock

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита запроса и синхронизации аппаратных часов реального времени (RTC / CMOS, микросхема Motorola MC146818).

### Использование
```bash
hwclock [ОПЦИИ]...
```

### Поддерживаемые опции
- `-r, --show` — считать и отобразить текущее время аппаратных часов RTC (действие по умолчанию).
- `-w, --systohc` — записать системное время ядра в аппаратные часы RTC.
- `-s, --hctosys` — установить системное время ядра из аппаратных часов RTC.
- `-u, --utc` — аппаратные часы хранят время в шкале всемирного координированного времени (UTC).
- `-l, --localtime` — аппаратные часы хранят местное (локальное) время.
- `-v, --verbose` — подробный вывод процесса синхронизации.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: прямое взаимодействие с драйвером CMOS RTC через `/proc/driver/rtc` и порты ввода-вывода `0x70`/`0x71`, чтение и запись даты/времени, взаимная синхронизация системного и аппаратного таймеров.
- **Не реализовано**: расчет и компенсация аппаратного дрейфа часов (файл `/etc/adjtime`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/hwclock`
