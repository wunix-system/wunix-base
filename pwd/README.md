# pwd

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита вывода абсолютного пути к текущему рабочему каталогу процесса (Print Working Directory).

### Использование
```bash
pwd
```

### Принцип работы
Выполняет системный вызов ядра Wunix `getcwd`, считывая канонический путь текущего каталога вызывающего процесса, и выводит его в стандартный поток вывода с переводом строки.

## Статус реализации

- **Реализовано**: считывание пути через системный вызов `getcwd`, локализованная обработка ошибок.
- **Не реализовано**: опции разрешения символических ссылок (`-L` логический путь с сохранением симлинков, `-P` физический путь — системный вызов ядра всегда возвращает канонический физический путь).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/pwd`
