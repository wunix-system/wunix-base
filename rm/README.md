# rm

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита удаления файлов и каталогов из файловой системы Wunix (POSIX rm).

### Использование
```bash
rm [ОПЦИЯ]... [ФАЙЛ...]
```

### Поддерживаемые опции
- `-f, --force` — принудительное удаление: игнорировать несуществующие файлы, не запрашивать подтверждения.
- `-r, -R, --recursive` — рекурсивное удаление каталогов и всего их содержимого.
- `-v, --verbose` — подробный вывод информации о каждом удаленном файле.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: удаление файлов через системный вызов `unlink`, рекурсивный обход и удаление вложенных каталогов (`-r`/`-R`), тихий режим (`-f`), локализация сообщений об ошибках.
- **Не реализовано**: интерактивный запрос подтверждения удаления каждого отдельного файла (`-i`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/rm`
