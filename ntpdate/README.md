# ntpdate

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Клиент протокола сетевой синхронизации времени NTP / SNTP (Network Time Protocol, RFC 5905, RFC 4330).
Позволяет опрашивать удаленные серверы точного времени по протоколу UDP (порт 123), вычислять сетевую задержку, смещение часов и синхронизировать системные часы Wunix и аппаратный таймер CMOS RTC.

### Использование
```bash
ntpdate [ОПЦИИ]... [СЕРВЕР]...
```

### Поддерживаемые опции
- `-q` — опрос серверов без изменения системных часов (query only).
- `-b` — ступенчатая установка системного времени ядра (step time).
- `-u` — использование непривилегированного UDP-порта.
- `-s` — тихий режим работы.
- `-v` — подробный вывод параметров соединения (stratum, delay, offset).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Примеры
```bash
# Синхронизация времени с сервером по умолчанию (pool.ntp.org)
ntpdate

# Проверка текущего смещения времени относительно Google NTP
ntpdate -q time.google.com

# Синхронизация с локальным шлюзом
ntpdate 10.0.2.2
```
