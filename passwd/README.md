# passwd

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита смены пароля учетной записи пользователя в операционной системе Wunix.

### Использование
```bash
passwd [ОПЦИЯ]... [ПОЛЬЗОВАТЕЛЬ]
```

### Поддерживаемые опции
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Безопасность и алгоритм
- Обычные пользователи могут изменять только собственный пароль (требуется ввод и подтверждение текущего пароля).
- Суперпользователь `root` может изменить пароль любой учетной записи без ввода старого пароля.
- Ввод паролей в консоли производится в защищенном режиме без эхо-печати символов.
- Для хэширования используется криптостойкий алгоритм SHA-512 с генерацией случайной криптографической соли. Результат записывается в системный файл `/etc/shadow` с сохранением прав доступа `0600`.

## Статус реализации

- **Реализовано**: хэширование SHA-512, проверка старого пароля для непривилегированных пользователей, подтверждение нового пароля, атомарное обновление `/etc/shadow`.
- **Не реализовано**: политики сложности паролей (минимальная длина символов, требования к спецсимволам, срок действия паролей).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/passwd`
