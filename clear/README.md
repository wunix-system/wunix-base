# clear

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита очистки экрана консоли и виртуального терминала Wunix.

### Использование
```bash
clear
```

### Принцип работы
Отправляет в стандартный поток вывода стандартную последовательность управляющих кодов ANSI:
- `[2J` — полная очистка видимой области экрана терминала.
- `[H` — позиционирование текстового курсора в левый верхний угол (строка 1, столбец 1).

## Статус реализации

- **Реализовано**: полная очистка экрана и возврат курсора в исходную позицию через ANSI/VT100 escape-коды.
- **Не реализовано**: очистка истории прокрутки терминала (scrollback buffer `[3J`) — зависит от поддержки эмулятором терминала.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/clear`
