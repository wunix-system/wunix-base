# curl

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Сетевой клиент командной строки для выполнения HTTP-запросов и передачи данных по сети.

### Использование
```bash
curl [ОПЦИИ...] <URL>
```

### Поддерживаемые опции
- `-o, --output <файл>` — сохранение полученного ответа сервера в указанный локальный файл.
- `-O, --remote-name` — сохранение ответа в файл с именем, извлеченным из URL.
- `-i, --include` — включение HTTP-заголовков ответа в выходной поток.
- `-I, --head` — выполнение запроса метода HEAD (получение только HTTP-заголовков).
- `-X, --request <команда>` — указание произвольного метода HTTP-запроса (GET, POST, PUT, DELETE, HEAD).
- `-d, --data <данные>` — передача тела данных HTTP POST запроса.
- `-H, --header <строка>` — добавление пользовательского HTTP-заголовка.
- `-s, --silent` — тихий режим работы (скрытие индикации и сообщений об ошибках).
- `-S, --show-error` — отображение сообщений об ошибках при включенном тихом режиме.
- `-k, --insecure` — разрешение небезопасных SSL/TLS соединений (без проверки сертификата).
- `--cacert <файл>` — явное указание пути к пользовательскому бандлу CA-сертификатов.
- `-v, --verbose` — подробный вывод информации об установлении сетевого соединения, TLS-рукопожатии и HTTP-транзакции.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы и сборки OpenSSL.

## Статус реализации

- **Реализовано**: протоколы HTTP/1.0, HTTP/1.1 и защищенный HTTPS/TLS поверх TCP-сокетов (с криптографическим стеком OpenSSL 4.2 и верификацией сертификатов X.509 через `/etc/ssl/certs/ca-certificates.crt`), методы GET, POST, HEAD, произвольные методы (`-X`), передача тела запроса и пользовательских заголовков, сохранение в файлы (`-o`, `-O`).
- **Не реализовано**: автоматический переход по перенаправлениям (`-L, --location`), сохранение и передача cookie (`-b`, `-c`), докачка файлов (`-C`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/curl`
