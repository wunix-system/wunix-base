# lsmod

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита отображения списка загруженных драйверов и модулей ядра операционной системы Wunix.

### Использование
```bash
lsmod [ОПЦИИ]...
```

### Поддерживаемые опции
- `-s, --sort-size` — сортировка списка модулей по занимаемому объему оперативной памяти.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Отображаемые поля
Считывает данные из `/proc/modules` и отображает:
- Имя модуля или драйвера (например, `virtio_net`, `virtio_blk`, `ps2_keyboard`).
- Объем памяти, занимаемый кодом и структурами драйвера.
- Счетчик активных ссылок/использования (Used by count).
- Список зависимых компонентов.

## Статус реализации

- **Реализовано**: парсинг `/proc/modules`, форматированный табличный вывод, сортировка по размеру памяти (`-s`).
- **Не реализовано**: динамическая выгрузка модулей (в текущей архитектуре ядра встроенные драйверы регистрируются монолитно).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/lsmod`
