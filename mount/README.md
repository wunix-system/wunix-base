# mount

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита монтирования файловых систем в общее дерево виртуальной файловой системы (VFS) Wunix.

### Использование
```bash
mount
mount [ОПЦИИ] -t <тип> <устройство> <каталог>
```

### Поддерживаемые опции
- `-t, --types <тип>` — указание типа файловой системы (`fat32`, `procfs`, `sysfs`, `devfs`, `ramfs`).
- `-o, --options <опции>` — параметры монтирования через запятую (`ro` только для чтения, `rw` чтение и запись, `remount` перемонтирование).
- `-v, --verbose` — подробный вывод сообщений о процессе монтирования.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

При вызове без аргументов утилита отображает список всех текущих активных точек монтирования VFS.

## Статус реализации

- **Реализовано**: монтирование блочных накопителей с FAT32, псевдофайловых систем ядра, вывод активных точек монтирования из `/proc/mounts`, обработка флагов `ro`/`rw`.
- **Не реализовано**: монтирование сетевых накопителей (NFS, CIFS/SMB), поддержка файловых систем Linux ext2/ext3/ext4.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/mount`
