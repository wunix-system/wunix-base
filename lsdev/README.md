# lsdev

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита сводной инспекции аппаратных ресурсов и привязки системных драйверов в Wunix.

### Использование
```bash
lsdev [ОПЦИИ]...
```

### Поддерживаемые опции
- `--irq` — отображение только таблицы распределения аппаратных прерываний (IRQ).
- `--ioports` — отображение только диапазонов портов ввода-вывода (I/O ports).
- `--iomem` — отображение только регионов физической памяти устройств (MMIO).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Принцип работы
Агрегирует и сопоставляет информацию из псевдофайлов ядра Wunix: `/proc/interrupts`, `/proc/ioports`, `/proc/iomem`, `/proc/devices` и `/proc/modules`.

## Статус реализации

- **Реализовано**: сбор данных по прерываниям, портам и адресам памяти, форматирование сводной таблицы распределения ресурсов между контроллерами.
- **Не реализовано**: на текущий момент все функции утилиты полностью реализованы.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/lsdev`
