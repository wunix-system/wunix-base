# ln

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита создания символических ссылок на файлы и каталоги (POSIX ln).

### Использование
```bash
ln [КЛЮЧИ]... ЦЕЛЬ [ИМЯ_ССЫЛКИ]
ln [КЛЮЧИ]... ЦЕЛЬ... КАТАЛОГ
```

### Поддерживаемые опции
- `-s, --symbolic` — создание символической ссылки (symlink).
- `-f, --force` — принудительное удаление существующего целевого файла или ссылки перед созданием новой.
- `-v, --verbose` — подробный вывод информации о создаваемых ссылках.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: создание символических ссылок (`ln -s`) через системный вызов `symlink`, перезапись существующих файлов при указании `-f`, подробные отчеты.
- **Не реализовано**: создание жестких ссылок (hard links) без ключа `-s` — файловые системы Wunix (FAT32 и ramfs) архитектурно не поддерживают жесткие ссылки.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/ln`
