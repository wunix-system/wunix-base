# time

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита измерения времени выполнения указанной команды и затраченных системных ресурсов.

### Использование
```bash
time [ОПЦИИ]... КОМАНДА [АРГУМЕНТЫ]...
```

### Поддерживаемые опции
- `-p, --portability` — вывод результатов в стандартном формате POSIX (`real`, `user`, `sys` в секундах).
- `-v, --verbose` — подробный вывод: время выполнения, процент использования CPU, максимальный объем занятой оперативной памяти (RSS).
- `-o, --output <файл>` — сохранение отчета в указанный файл вместо стандартного потока ошибок.
- `-a, --append` — добавление результатов в конец существующего файла (используется вместе с `-o`).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: запуск команды через `fork`/`execve`, замер астрономического времени с миллисекундной точностью, опрос системного счетчика `times`/`wait4`, поддержка POSIX и подробного формата.
- **Не реализовано**: расширенная статистика подсистемы ввода-вывода (количество переключений контекста, прочитанные секторы ввода-вывода I/O).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/time`
