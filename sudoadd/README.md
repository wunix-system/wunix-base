# sudoadd

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Специализированная административная утилита Wunix для безопасного управления привилегиями sudo пользователей.

### Использование
```bash
sudoadd [ОПЦИЯ] ИМЯ_ПОЛЬЗОВАТЕЛЯ
```

### Поддерживаемые опции
- `-d, --delete`, `-r, --remove` — отозвать права администратора (удалить пользователя из группы `wheel`).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Принцип работы
Проверяет существование учетной записи в `/etc/passwd`, выполняет корректное добавление или исключение пользователя из списка членов группы `wheel` в `/etc/group` с соблюдением атомарности записи.

## Статус реализации

- **Реализовано**: проверка учетной записи пользователя, добавление в административную группу `wheel`, удаление из группы (`-d`), проверка прав суперпользователя.
- **Не реализовано**: на текущий момент все функции утилиты полностью реализованы.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/sudoadd`
