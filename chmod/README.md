# chmod

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита изменения прав доступа (режимов доступа) к файлам и каталогам в файловой системе Wunix.

### Использование
```bash
chmod [ОПЦИЯ]... РЕЖИМ ФАЙЛ...
```

### Форматы режима
- **Восьмеричный режим**: числовые маски прав доступа, например `755`, `0644`, а также специальные биты `4755` (SUID), `2755` (SGID), `1777` (Sticky bit).
- **Символьный режим**: модификация прав в формате `[ugoa][+-=][rwxXst]`, например `+x`, `u+rwx`, `go-w`, `a=r`.

### Поддерживаемые опции
- `-R, --recursive` — рекурсивное изменение прав доступа для каталогов и их содержимого.
- `-v, --verbose` — подробный вывод информации о каждом обработанном файле.
- `-c, --changes` — вывод информации только об объектах, у которых права были фактически изменены.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: парсинг восьмеричных и символьных режимов доступа, поддержка битов SUID/SGID/Sticky, рекурсивная обработка дерева каталогов (`-R`), подробные отчеты (`-v`, `-c`), локализация сообщений об ошибках.
- **Не реализовано**: на текущий момент все заявленные функции полностью реализованы в рамках модели разрешений ядра Wunix.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/chmod`
