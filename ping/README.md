# ping

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита сетевой диагностики для проверки доступности сетевых узлов и замера задержек передачи пакетов (ICMP Echo Request).

### Использование
```bash
ping [ОПЦИИ] <хост>
```

### Поддерживаемые опции
- `-c <число>` — количество отправляемых пакетов перед завершением работы.
- `-s <размер>` — размер полезной нагрузки ICMP пакета в байтах (по умолчанию 56 байт, что дает размер IP-пакета 64 байта).
- `-W <таймаут>` — таймаут ожидания ответа на пакет в секундах.
- `-4` — принудительное использование протокола IPv4.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Статистика
По завершении работы выводит статистику: отправлено, получено, процент потерь пакетов, минимальное, среднее, максимальное время прохождения пакетов (RTT min/avg/max/mdev). Обрабатывает прерывание комбинацией клавиш `Ctrl+C`.

## Статус реализации

- **Реализовано**: отправка ICMP Echo Request через сырые сокеты (`SOCK_RAW`), прием Echo Reply, расчет кругового времени RTT с миллисекундной точностью, подсчет статистики и прерывание по `Ctrl+C`.
- **Не реализовано**: протокол IPv6 (ICMPv6), режим непрерывного флуд-пинга (`-f`), запись маршрута пакетов (Record Route).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/ping`
