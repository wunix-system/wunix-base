# reboot

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита перезапуска и аппаратного сброса операционной системы Wunix.

### Использование
```bash
reboot [ОПЦИИ]...
```

### Поддерживаемые опции
- `-f, --force` — немедленный аппаратный сброс без предварительного завершения запущенных процессов.
- `-p, --poweroff` — вместо перезагрузки выключить питание компьютера (эквивалентно `poweroff`).
- `-w, --wtmp-only` — только имитация действия без реального перезапуска.
- `-d, --no-wtmp` — не производить запись события в системный журнал.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Принцип работы
Выполняет сброс буферов файловой системы на постоянные накопители (`sync`), отправляет процессам сигнал завершения и производит перезагрузку платформы через интерфейсы ACPI или порт сброса контроллера клавиатуры 8042.

## Статус реализации

- **Реализовано**: сброс дисковых кэшей, вызов системного вызова `reboot`, принудительная перезагрузка (`-f`), переход в режим выключения питания (`-p`).
- **Не реализовано**: журналирование в бинарные базы `/var/log/wtmp` (Wunix использует текстовые журналы).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/reboot`
