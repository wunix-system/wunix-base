# userdel

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита удаления учетной записи пользователя из операционной системы Wunix.

### Использование
```bash
userdel [ОПЦИЯ]... ИМЯ_ПОЛЬЗОВАТЕЛЯ
```

### Поддерживаемые опции
- `-r, --remove` — рекурсивно удалить домашний каталог пользователя и связанные с ним файлы.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Модифицируемые файлы
Удаляет запись указанного пользователя из системных конфигурационных файлов `/etc/passwd`, `/etc/shadow` и `/etc/group`.

## Статус реализации

- **Реализовано**: проверка учетной записи, удаление из баз пользователей и групп, рекурсивное удаление домашнего каталога при ключе `-r`.
- **Не реализовано**: проверка активных запущенных процессов удаляемого пользователя перед удалением.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/userdel`
