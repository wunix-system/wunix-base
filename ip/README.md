# ip

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита мониторинга и конфигурации сетевых интерфейсов, IP-адресов и таблицы маршрутизации (семейство iproute2).

### Использование
```bash
ip [ОПЦИИ] ОБЪЕКТ [КОМАНДА]
```

### Поддерживаемые объекты
- `link` (`l`) — сетевые интерфейсы (просмотр состояния, MAC-адресов, MTU, флагов UP/DOWN).
- `addr` (`a`) — сетевые протокольные адреса (IPv4-адреса и маски подсетей).
- `route` (`r`) — таблица статической и динамической маршрутизации IPv4 (шлюз по умолчанию, маршруты подсетей).

### Поддерживаемые опции
- `-br, -brief` — вывод информации в компактном табличном виде (одна строка на интерфейс).
- `-h, --help` — вывод справочной информации.
- `-V, -Version, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: чтение и форматирование информации об интерфейсах через `/proc/net/dev`, адресах через `/proc/net/if_inet` и маршрутах через `/proc/net/route`, компактный режим `-br`.
- **Не реализовано**: динамическое изменение параметров интерфейсов из командной строки (`ip link set up/down`, `ip addr add`, `ip route add`) — базовая конфигурация сети выполняется ядром и сценариями инициализации.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/ip`
