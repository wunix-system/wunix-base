# man

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Интерактивная система просмотра руководств пользователя и справочной документации Wunix (POSIX man).

### Использование
```bash
man [РАЗДЕЛ] <страница>
man -k <ключевое_слово>
man -f <команда>
```

### Поддерживаемые опции
- `-k, --apropos <слово>` — полнотекстовый поиск по кратким описаниям всех доступных справочных страниц.
- `-f, --whatis <команда>` — вывод краткой однострочной справки по указанной утилите.
- `-a, --all` — последовательный просмотр всех найденных страниц из разных разделов.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Возможности
- Встроенный парсер языка разметки roff/mandoc (`.TH`, `.SH`, `.SS`, `.B`, `.I`, `.PP`, `.TP`).
- Интерактивный терминальный пейджер с поддержкой скроллинга стрелками и клавишами `Page Up`/`Page Down`/`Space`, перехода в начало (`g`) и конец (`G`), поиска по тексту (`/`) и выхода (`q`).
- Двуязычная база руководств (автоматический выбор между русской и английской локалью в зависимости от системного языка ядра).

## Статус реализации

- **Реализовано**: полнофункциональный пейджер, парсер разметки roff, подсветка синтаксиса, поиск по ключевым словам (`-k`) и именам (`-f`), встроенная документация по базовым системным утилитам.
- **Не реализовано**: внешнее сжатие страниц архиватором gzip (страницы хранятся в открытом текстовом формате roff).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/man`
