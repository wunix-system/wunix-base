# id

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита отображения информации о реальных и эффективных идентификаторах пользователя (UID) и групп (GID).

### Использование
```bash
id [ОПЦИЯ]... [ПОЛЬЗОВАТЕЛЬ]
```

### Поддерживаемые опции
- `-u, --user` — вывести только числовой идентификатор пользователя (UID).
- `-g, --group` — вывести только числовой идентификатор основной группы (GID).
- `-G, --groups` — вывести список всех идентификаторов групп, в которые входит пользователь.
- `-n, --name` — вывести текстовое имя вместо числового идентификатора (используется вместе с `-u`, `-g`, `-G`).
- `-r, --real` — вывести реальный идентификатор вместо эффективного.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

При вызове без аргументов выводит полную строку учетных данных: `uid=... gid=... groups=...`.

## Статус реализации

- **Реализовано**: чтение UID/GID через системные вызовы `getuid`, `geteuid`, `getgid`, `getegid`, разрешение имен через `/etc/passwd` и `/etc/group`, поддержка запроса данных произвольного пользователя по имени.
- **Не реализовано**: на текущий момент все заявленные функции полностью реализованы в рамках системы разграничения прав Wunix.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/id`
