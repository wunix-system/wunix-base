# system

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Легковесная, понятная человеку и полностью функциональная система управления и супервизии служб (демонов) Wunix.
Обеспечивает управление жизненным циклом сервисов, автозапуск, просмотр цветных статусов, интеграцию с редактором `nano` и прозрачное журналирование в `/var/log/services/`.

### Использование
```bash
system <КОМАНДА> [ПАРАМЕТРЫ]...
```

### Команды управления
- `system start <СЛУЖБА>` — запуск службы.
- `system stop <СЛУЖБА>` — остановка службы.
- `system restart <СЛУЖБА>` — перезапуск службы.
- `system enable <СЛУЖБА>` — включение автозапуска службы при загрузке ОС (символическая ссылка в `/etc/services/enabled/`).
- `system disable <СЛУЖБА>` — отключение автозапуска службы.
- `system status [СЛУЖБА]` — подробный цветной статус службы (PID, время работы, последние строки лога) или список всех служб при отсутствии аргумента.
- `system list` — вывод таблицы всех установленных служб и их состояния.
- `system edit <СЛУЖБА>` — открытие файла конфигурации службы в редакторе `nano`.
- `system create <СЛУЖБА>` — генерация понятного шаблона службы с комментариями и открытие в `nano`.
- `system logs <СЛУЖБА>` — просмотр текстового журнала службы.

### Параметры команды `logs`
- `-n, --lines <N>` — вывод последних `N` строк журнала (по умолчанию 20).
- `--head <N>` — вывод первых `N` строк журнала.
- `-f, --follow` — непрерывное отслеживание журнала в реальном времени.

### Формат файла службы (`/etc/services/<имя>.conf`)
Конфигурация службы максимально проста и наглядна:
```ini
# Служба синхронизации времени Wunix
description = Фоновая синхронизация времени по NTP
command = /bin/timesyncd -1
autostart = yes
restart = on-failure
user = root
directory = /
```
