# cat

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита для последовательного чтения, вывода и конкатенации содержимого файлов или стандартного потока ввода (POSIX cat).

### Использование
```bash
cat [ФАЙЛ...]
```

### Возможности
- Чтение одного или нескольких файлов, переданных в аргументах командной строки.
- Чтение из стандартного потока ввода (`stdin`), если аргументы не указаны или передан дефис `-`.
- Потоковый буферизованный вывод содержимого без загрузки всего файла целиком в оперативную память.
- Информативные локализованные сообщения об ошибках (отсутствие файла, ошибки доступа `EACCES`/`EPERM`).

## Статус реализации

- **Реализовано**: базовый ввод/вывод файлов и потока `stdin`, последовательная конкатенация нескольких файлов, обработка ошибок файловых дескрипторов.
- **Не реализовано**: расширенные флаги GNU coreutils (`-n` нумерация строк, `-b` нумерация непустых строк, `-s` сжатие пустых строк, `-E` отображение концов строк, `-T` отображение символов табуляции, `-v` отображение непечатаемых символов).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/cat`
