# touch

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита создания пустых файлов или обновления времени последнего доступа и модификации (POSIX touch).

### Использование
```bash
touch [ОПЦИИ]... ФАЙЛ...
```

### Принцип работы
Для каждого указанного пути к файлу:
- Если файл не существует, он создается как пустой файл с правами доступа по умолчанию (`0644`).
- Если файл уже существует, обновляется время его последней модификации.

## Статус реализации

- **Реализовано**: создание новых пустых файлов через системный вызов `open` с флагом `O_CREAT`, обновление дескрипторов существующих файлов, локализация сообщений об ошибках.
- **Не реализовано**: флаги выборочного изменения времени (`-a` только время доступа, `-m` только время модификации), запрет создания новых файлов (`-c, --no-create`), задание произвольной даты (`-d`, `-t`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/touch`
