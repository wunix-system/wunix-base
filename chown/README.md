# chown

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита изменения владельца и группы файлов и каталогов в операционной системе Wunix.

### Использование
```bash
chown [ОПЦИЯ]... [ВЛАДЕЛЕЦ][:[ГРУППА]] ФАЙЛ...
```

### Форматы спецификации владельца
- `пользователь` — изменение только владельца файла.
- `пользователь:группа` или `пользователь.группа` — одновременное изменение владельца и группы.
- `:группа` — изменение только группы файла.
- Поддерживаются как текстовые имена пользователей и групп (с разрешением через `/etc/passwd` и `/etc/group`), так и числовые идентификаторы UID/GID.

### Поддерживаемые опции
- `-R, --recursive` — рекурсивное изменение владельца и группы для каталогов и их содержимого.
- `-v, --verbose` — подробный отчет о каждом обработанном файле.
- `-c, --changes` — вывод информации только при фактическом изменении параметров файла.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: разрешение имен пользователей и групп через конфигурационные файлы `/etc/passwd` и `/etc/group`, числовые UID/GID, рекурсивный обход каталогов (`-R`), флаги подробного вывода (`-v`, `-c`), проверка прав суперпользователя.
- **Не реализовано**: обработка параметров разыменования символических ссылок (`--dereference` / `-H`, `-L`, `-P` — по умолчанию обрабатывается сама цель ссылки).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/chown`
