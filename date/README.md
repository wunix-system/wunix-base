# date

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита отображения и установки системного времени и даты операционной системы Wunix.

### Использование
```bash
date [ОПЦИИ]... [+ФОРМАТ]
date [-u|--utc] [MMDDhhmm[[CC]YY][.ss]]
```

### Поддерживаемые опции
- `-d, --date=СТРОКА` — вывод времени, заданного в текстовом формате (`@timestamp`, `YYYY-MM-DD HH:MM:SS`, `HH:MM:SS`).
- `-s, --set=СТРОКА` — установка системного времени ядра из заданной строки или временной метки.
- `-u, --utc, --universal` — работа в шкале всемирного координированного времени (UTC).
- `-R, --rfc-email` — форматирование даты по стандарту RFC 5322 (например, `Fri, 30 Oct 2026 13:00:23 +0300`).
- `-I[ФОРМАТ], --iso-8601[=ФОРМАТ]` — вывод даты в стандарте ISO 8601 (`date`, `hours`, `minutes`, `seconds`).
- `-r, --reference=ФАЙЛ` — отображение времени последней модификации указанного файла.
- `+ФОРМАТ` — пользовательский шаблон вывода (`%Y`, `%m`, `%d`, `%H`, `%M`, `%S`, `%F`, `%T`, `%Z`, `%z`, `%a`, `%b` и др.).
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: отображение текущего времени и даты, форматирование по шаблонам, ISO 8601, RFC 5322, чтение времени модификации файлов, работа в UTC и локальном времени, установка системного времени через системный вызов ядра, автоматическая синхронизация с удаленными серверами времени по протоколу NTP (службы `ntpdate` и `timesyncd`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/date`
