# wsh

> Командный интерпретатор (Wunix Shell) операционной системы Wunix.

## Описание

`wsh` (Wunix Shell) — официальная интерактивная командная оболочка для операционной системы Wunix.

Оболочка сочетает стандарты синтаксиса командной строки POSIX Shell и эргономичные интерактивные возможности современного терминала (подсветка синтаксиса в реальном времени, контекстное автодополнение, навигация по истории команд).

### Использование

```bash
wsh [ОПЦИИ] [СКРИПТ]
```

### Возможности и архитектура

- **Интерактивный редактор строк**: перемещение курсора стрелками влево/вправо, прыжки по словам (`Ctrl+Left`/`Ctrl+Right`), переход в начало и конец строки (`Home`/`End`), удаление символов (`Backspace`, `Delete`), кольцевой буфер истории команд (`Up`/`Down`).
- **Контекстное автодополнение**: быстрое дополнение по нажатию клавиши `Tab`:
  - поиск и дополнение имен исполняемых файлов из переменной окружения `PATH` (`/bin`);
  - контекстное автодополнение имен встроенных команд (built-ins);
  - дополнение относительных и абсолютных путей к файлам и каталогам VFS.
- **Подсветка синтаксиса в реальном времени**: динамическая цветовая разметка вводимого текста:
  - **Зеленый цвет** — валидная исполняемая программа или встроенная команда;
  - **Красный цвет** — неизвестная команда или некорректный синтаксис;
  - **Желтый цвет** — строковые литералы, кавычки и специальные метасимволы.
- **Конвейеры (Pipelines)**: объединение команд через оператор `|` (например, `cat /etc/passwd | top`) с использованием системного вызова `sys_pipe2`.
- **Перенаправление ввода-вывода (Redirections)**:
  - перенаправление стандартного вывода в файл с перезаписью (`>`);
  - перенаправление вывода в режиме добавления (`>>`);
  - перенаправление стандартного ввода из файла (`<`).
- **Переменные окружения**: раскрытие переменных `$VAR` и `${VAR}`, автоматическая инициализация системных переменных `PATH`, `HOME`, `USER`, `PWD`.
- **Встроенные команды (Built-ins)**: `cd`, `pwd`, `echo`, `exit`, `history`, `clear`, `export`, `set`, `help`, `alias`, `source`.
- **Постоянная история команд**: команды сохраняются между сессиями пользователя в файле истории (`~/.wsh_history` или `$HISTFILE`). Поддерживаются мгновенная запись при вводе, автоматическая дедупликация и лимитирование размера (`HISTSIZE`), а также управление историей (`history [N]`, `-c`, `-d`, `-w`, `-r`, `-a`).
- **Пакетный запуск сценариев**: выполнение командных скриптов построчно (`wsh /etc/init.sh`).

## Статус реализации

- **Реализовано**: интерактивный редактор строк, автодополнение по Tab, подсветка синтаксиса, конвейеры `|`, перенаправление дескрипторов `>`, `>>`, `<`, раскрытие переменных окружения, встроенные команды, пакетный запуск сценариев.
- **Запланировано**: сложные управляющие конструкции скриптового языка (циклы `for`/`while`, условные ветвления `if`/`then`/`else`/`fi`, функции пользователя), управление фоновыми заданиями (`job control`, `&`, `fg`, `bg`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/wsh`
