# readlink

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита чтения целевого значения символических ссылок и канонизации путей файлов.

### Использование
```bash
readlink [КЛЮЧИ]... ФАЙЛ...
```

### Поддерживаемые опции
- `-f, --canonicalize` — канонизация пути: рекурсивное разрешение всех символических ссылок и относительных сегментов пути (`.`, `..`). Все элементы пути должны существовать.
- `-n, --no-newline` — подавление вывода завершающего символа перевода строки.
- `-q, --quiet`, `-s, --silent` — подавление вывода большинства сообщений об ошибках.
- `-v, --verbose` — подробный вывод диагностических сообщений об ошибках.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

## Статус реализации

- **Реализовано**: системный вызов `readlink`, разрешение символических ссылок, канонизация путей (`-f`), подавление перевода строки (`-n`), тихий режим.
- **Не реализовано**: на текущий момент все функции утилиты полностью реализованы.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/readlink`
