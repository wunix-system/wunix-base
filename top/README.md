# top

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита мониторинга системных процессов, загрузки процессора и использования оперативной памяти в Wunix.

### Использование
```bash
top
```

### Отображаемая информация
- Заголовок системы: текущее время, общее время непрерывной работы (uptime), количество запущенных процессов.
- Использование оперативной памяти: общий объем физической памяти, свободная память, память буферов и кэшей ядра.
- Таблица активных процессов: идентификатор (PID), пользователь (USER), приоритет (PR), виртуальная память (VIRT), резидентная память (RES), статус процесса (S: Running, Sleeping, Zombie), затраченное время CPU (TIME+) и командная строка (COMMAND).

## Статус реализации

- **Реализовано**: считывание информации из `/proc`, опрос системной таблицы задач ядра, вывод форматированной таблицы процессов и сводки памяти.
- **Не реализовано**: интерактивный curses-интерфейс с динамической пересортировкой по полям (по нажатию `P`, `M`, `T`), отправка сигналов процессам (`k`) и настройка приоритетов (`r`) из интерфейса — утилита работает в режиме моментального снимка состояния.

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/top`
