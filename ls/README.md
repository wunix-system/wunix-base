# ls

> Программа входит в состав базового набора системных утилит `wunix-base` операционной системы Wunix.

## Описание

Утилита отображения содержимого каталогов и информации о файлах (POSIX ls).

### Использование
```bash
ls [КЛЮЧИ]... [ФАЙЛ...]
```

### Поддерживаемые опции
- `-l` — подробный список: тип файла, права доступа (rwxrwxrwx), число ссылок, владелец, группа, размер в байтах и имя.
- `-a, --all` — отображение всех файлов, включая скрытые файлы, начинающиеся с точки (`.` и `..`).
- `-h, --human-readable` — вывод размеров файлов в удобном формате (K, M, G) вместе с флагом `-l`.
- `-h, --help` — вывод справочной информации.
- `-V, --version` — вывод версии программы.

### Цветовая подсветка
Автоматически подсвечивает объекты в терминале по цветам:
- Каталоги — синий цвет.
- Исполняемые файлы — зеленый цвет.
- Символические ссылки — бирюзовый цвет.
- Специальные блочные и символьные устройства — желтый цвет.

## Статус реализации

- **Реализовано**: чтение каталогов через `getdents64`, подробный режим `-l`, отображение скрытых файлов `-a`, человекочитаемые размеры `-h`, чтение символических ссылок и цветовая подсветка типов файлов.
- **Не реализовано**: многоколоночный табличный вывод по ширине терминала, сортировка по времени модификации (`-t`) и по размеру (`-S`), рекурсивный вывод подкаталогов (`-R`).

## Сборка

Для сборки утилиты необходим компилятор Rust с поддержкой целевой архитектуры `x86_64-unknown-none`.

```bash
# Добавление целевой платформы
rustup target add x86_64-unknown-none

# Сборка исполняемого файла в режиме release
cargo build --release --target x86_64-unknown-none
```

Скомпилированный исполняемый файл формата ELF64 будет находиться по пути:
`target/x86_64-unknown-none/release/ls`
